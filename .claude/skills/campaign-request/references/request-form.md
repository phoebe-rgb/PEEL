# Campaign request form

Give this to whoever is asking for an email. They do **not** need a Klaviyo login or a
Claude account — they fill this in anywhere (Slack, email, a Google Form, a Notion
page) and send it over. The operator pastes it into `/campaign-request`.

The form exists because the expensive part of a request is never the building; it is
the four rounds of "which audience?", "which link?", "is this the final image?".

---

## Copy-paste template

```
CAMPAIGN REQUEST

Requested by:
Date requested:

1. What is this email?
   (occasion / campaign name — e.g. "VIP 14k launch", "Archive restock")

2. Who should get it?
   (list or segment name. Anyone to exclude?)

3. When would you like it to go out?
   (date + rough time. This is a request — nothing gets scheduled without a human.)

4. Subject line
   (your version, or "write it for me" + the angle you want)

5. Preview text
   (the grey line after the subject. Not a repeat of the subject.)

6. What does the email say?
   (the actual copy, or bullets to write from — offer, key message, any must-say)

7. Main button — what does it say, and where does it go?
   Button text:
   Destination URL:

8. Images
   (public links, or Drive/Canva. Say which is the hero.)

9. Start from an existing email?
   ( ) Yes — which one (name or link):
   ( ) No — build fresh

10. Anything else
    (legal must-say, a date that cannot slip, who signs off)
```

---

## What "done" looks like back to the requester

They get, in return:

- a link to the **template** in Klaviyo and a link to the **campaign draft**
- the audience it is pointed at, with the estimated recipient count
- a list of what was checked, including anything that failed
- a list of what still needs a human: approve copy, confirm audience, schedule, send

Nothing is sent. Nothing is scheduled. That is the deal, and it is worth saying out
loud in the reply so nobody assumes the email went out.

---

## Fields that block, vs fields that can wait

Blocking — cannot build without them:

- **2. Audience.** No guessing. An unmatched name stops that item.
- **7. Destination URL.** A button with nowhere to go is not a draft, it is a bug.

Everything else can be drafted from an assumption, as long as the assumption is
stated in the handover. Missing subject → write one and flag it. Missing images →
build with placeholders clearly marked and list them as outstanding.

---

## Running it without a form

Most requests arrive as prose in a message, not as a filled form. That is fine —
map what arrived onto the fields above, show the mapping as a table, and ask only
about blocking gaps. Do not send the form back and wait. Build what can be built.
